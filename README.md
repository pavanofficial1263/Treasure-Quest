# Treasure Quest

## Board Game Design

Treasure Quest is an academic board game design project created using Adobe Photoshop.

## Project Overview

The project is based on a treasure-hunt themed board game. I designed the overall board layout, visual composition, game elements, and presentation.

## My Contribution

- Designed the overall board layout
- Planned the game structure and visual composition
- Arranged game elements
- Edited and composed the final board in Adobe Photoshop
- Developed the treasure-hunt theme and presentation

## Tools Used

- Adobe Photoshop
